## 5. Movimento

Biblioteca: pacote **`motion`** (`motion/react`), substituindo `framer-motion`.
`<MotionConfig reducedMotion="user">` na raiz: com "reduzir movimento" ativo,
tudo aparece sem deslocamento nem desfoque.

| Onde | Efeito | Detalhe |
|---|---|---|
| Topo, ao carregar | Foto sobe e assenta; "LEONARDO" revelado por letra sob máscara; polaroide e cartão entram em sequência | Mola suave, total ≤ 1,2 s |
| Topo, no scroll | Parallax: "CAVALCANTI" e foto em velocidades diferentes | `useScroll` + `useTransform` |
| Polaroide | Inclina seguindo o cursor | `useSpring`, só em ponteiro fino |
| Títulos | Palavras saem do desfoque (blur 12px → 0, y 20 → 0) | stagger 40 ms, uma vez por entrada |
| Prints | Revelação por `clip-path` + zoom leve no hover | |
| Números | Contagem até o valor | ao entrar na tela, uma vez |
| Seção preta | Palavras acendem com o progresso do scroll | opacidade ligada ao scroll |
| FAQ | Altura animada | layout animation |
| Rodapé | "Cavalcanti®" sobe preso ao scroll | |
| Microinterações | Botões/links com resposta magnética sutil | ≤ 300 ms |

Animar só `transform`, `opacity`, `filter` e `clip-path`. Nada de animação em
loop infinito chamando atenção.

## 6. Arquitetura técnica

Stack mantida: React 18 · Vite 5 · TypeScript · Tailwind 3. Deploy: GitHub Pages
pelo workflow existente no push à `main`.

```
src/
  i18n/
    LangProvider.tsx   # contexto do idioma; ordem: ?lang= > escolha salva > navegador
    ui.ts              # textos de interface { pt, en }
    useT.ts
  data/
    projects.ts        # destaques + outros
    research.ts
    experience.ts
    stack.ts           # cada item com usedIn: ProjectId[]
    faq.ts
    stats.ts           # cada número com comentário da fonte
  components/
    sections/          # Hero, Stats, Projects, Research, Stack, Experience, Faq, Contact
    layout/            # Header, Footer
    ui/                # BlurText, Label, Polaroid, TalkCard, Magnetic
  assets/
    me/                # foto recortada (WebP + PNG de reserva)
    shots/             # prints dos projetos
public/cv/             # CV em PDF
```

- Tipo base: `type Localized<T = string> = { pt: T; en: T }`.
- `LangProvider` atualiza `<html lang>` e grava a escolha em `localStorage`
  dentro de `try/catch` (a página funciona sem ele).
- Removidos: `FocusAreas`, `References`, `About`, `Skills` antigos e os dados
  `focusAreas.ts`, `references.ts`, `skills.ts`.

### Imagens
- Foto: recorte feito uma vez, fora do build; exportada em WebP (altura 1200 px)
  e PNG de reserva; `width`/`height` declarados e `fetchpriority="high"`. O JPG
  original não entra no repositório. Conferida sobre fundo laranja, claro e
  preto.
- Prints públicos capturados ao vivo em 1440×900; demais com `loading="lazy"`.
- Intranet de IA: ilustração do fluxo, sem nenhum dado real.

### SEO e compartilhamento
- `og-image.png` 1200×630 novo, na identidade laranja com a foto.
- JSON-LD `Person` atualizado: `jobTitle`, `alumniOf` UFRN, `sameAs` (GitHub,
  LinkedIn), `knowsAbout` = lista enxuta.
- Metas em PT no `index.html` (SPA: o card social é um só).
